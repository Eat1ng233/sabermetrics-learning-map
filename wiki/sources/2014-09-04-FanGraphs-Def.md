# Def — FanGraphs 綜合守備價值專題

- **作者**：Neil Weinberg
- **發表日期**：2014-09-04
- **出處**：[[entities/FanGraphs|FanGraphs]] Sabermetrics Library
- **原始連結**：[Def | Sabermetrics Library](https://library.fangraphs.com/defense/def/)
- **本地檔案**：`raw/articles/Def _ Sabermetrics Library.pdf`

## 核心摘要
1. **定義與公式**：`Def = Fielding Runs Above Average + Positional Adjustment`，聯盟平均為 `0`，約每 `9–10` 分等於 `1` 勝，為野手 [[metrics/WAR|WAR]] 的守備核心積木。
2. **為何需要位置調整**：[[metrics/UZR|UZR]] 與 [[metrics/DRS|DRS]] 僅衡量「相對於同守位平均」的表現，但游擊手平均守備難度與價值遠高於左外野手或一壘手；加入位置調整後才能跨守位直接比較。
3. **年份分界**：FanGraphs 於 2003 年（含）起採用 `UZR`，2002 年（含）以前採用 `TZ`（Total Zone）；捕手則採 `rSB` 與擋球指標。
