# LOB% — FanGraphs 殘壘率專題

- **作者**：Piper Slowinski
- **發表日期**：2010-02-17
- **出處**：[[entities/FanGraphs|FanGraphs]] Sabermetrics Library
- **原始連結**：[LOB% | Sabermetrics Library](https://library.fangraphs.com/pitching/lob/)
- **本地檔案**：`raw/articles/LOB% _ Sabermetrics Library.pdf`

## 核心摘要
1. **公式**：不使用 Box Score 的團隊殘壘，而是以投手被安打、保送、觸身球、全壘打與失分計算：$\text{LOB\%} = \frac{H + BB + HBP - R}{H + BB + HBP - 1.4 \times HR}$。
2. **均值回歸**：聯盟平均約 **70–72%**。顯著偏高或偏低的 LOB% 往往反映序列運氣，未來容易向聯盟平均回歸（例外：高三振率投手因能自己解決危機，通常能維持較高的真實 LOB%）。
