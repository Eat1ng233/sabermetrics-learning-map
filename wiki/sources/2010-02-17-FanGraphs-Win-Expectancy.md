# Win Expectancy — FanGraphs 勝率預期專題

- **作者**：Piper Slowinski
- **發表日期**：2010-02-17
- **出處**：[[entities/FanGraphs|FanGraphs]] Sabermetrics Library
- **原始連結**：[Win Expectancy | Sabermetrics Library](https://library.fangraphs.com/misc/we/)
- **本地檔案**：`raw/articles/Win Expectancy _ Sabermetrics Library.pdf`

## 核心摘要
1. **定義**：根據歷史近十年類似得分環境下的比賽結果，計算在特定「局數、比數、出局數、壘包狀態」下主隊或客隊最終贏球的機率（賽前預設 50/50，FanGraphs 另有納入主場優勢與先發強弱的 Game Odds）。
2. **定位**：為 [[metrics/WPA|WPA]] 與 [[metrics/LI|LI]] 的計算基礎，FanGraphs 提供每場比賽的即時 Win Expectancy 走勢圖（經典案例：2011 年世界大賽第六戰遊騎兵與紅雀的戲劇性反轉）。
3. **限制**：標準 WE 僅反映「聯盟平均球員」在該情境下的歷史勝率，不考量當下對決打者與投手的個人實力差異。
