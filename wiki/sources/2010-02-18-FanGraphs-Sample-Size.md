# FanGraphs — Sample Size

- **作者**：Piper Slowinski（2017 年 8 月由 Neil Weinberg 更新）
- **發布日期**：2010-02-18
- **原始檔案**：`raw/articles/Sample Size _ Sabermetrics Library.pdf`
- **原始連結**：[Sample Size | FanGraphs Sabermetrics Library](https://library.fangraphs.com/principles/sample-size/)

## 核心摘要
1. **指標不是「瞬間穩定」，而是「隨樣本漸進趨穩」**：Russell Carleton（Pizza Cutter）定義的「穩定點」是指分半相關係數達 $r = 0.7$（即 $R^2 = 0.49$）的門檻；Sean Dolinar 與 Jonah Pemstein 則以 Cronbach's Alpha 繪製隨每 10 PA 遞增的信度曲線，顯示邊際效益遞減（前 200 PA 的資訊增量遠大於後 200 PA）。
2. **影響穩定速度的因素**：牽涉變數越少的技能越快穩定（如三振率只取決於投打對決，打者僅需約 **60 PA**）；牽涉擊球品質、方向、天氣、守備與運氣的指標則極慢穩定（如投手 [[metrics/BABIP|BABIP]] 需約 **2,000 BIP**）。
3. **收錄完整門檻表**：整理打擊（15 項）與投球（15 項）的 Carleton $R^2 = 0.49$ 經驗法則參考門檻。
