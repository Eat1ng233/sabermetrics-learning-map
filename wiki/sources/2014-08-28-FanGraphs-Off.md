# Off — FanGraphs 綜合進攻價值專題

- **作者**：Neil Weinberg
- **發表日期**：2014-08-28
- **出處**：[[entities/FanGraphs|FanGraphs]] Sabermetrics Library
- **原始連結**：[Off | Sabermetrics Library](https://library.fangraphs.com/offense/off/)
- **本地檔案**：`raw/articles/Off _ Sabermetrics Library.pdf`

## 核心摘要
1. **定義與公式**：`Off = Batting Runs Above Average + BsR`，將經球場與聯盟校正後的打擊得分貢獻與綜合跑壘得分相加，同時衡量「品質」與「出賽量（PA）」，為野手 [[metrics/WAR|WAR]] 的進攻核心積木。
2. **尺度**：`0` 為聯盟平均（頂尖 `+45`、優秀 `+30`、高於平均 `+15`、極差 `-25`），約每 `9–10` 分等於 `1` 勝。
