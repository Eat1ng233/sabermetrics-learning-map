# Clutch — FanGraphs 關鍵時刻表現專題

- **作者**：Piper Slowinski
- **發表日期**：2010-02-17
- **出處**：[[entities/FanGraphs|FanGraphs]] Sabermetrics Library
- **原始連結**：[Clutch | Sabermetrics Library](https://library.fangraphs.com/misc/clutch/)
- **本地檔案**：`raw/articles/Clutch _ Sabermetrics Library.pdf`

## 核心摘要
1. **定義**：衡量球員在高關鍵時刻（High Leverage）相較於「在情境中立環境下以自身實力應有的表現」做得更好或更差，公式為 $\text{Clutch} = (\text{WPA} / \text{pLI}) - \text{WPA/LI}$。
2. **自我比較基準**：比較的是球員自己與自己（例如整季 `.300` 打者在高關鍵時刻也打 `.300`，Clutch 為 `0`）。
3. **描述過去而非預測未來**：多數球員落在 `-1` 至 `+1` 之間（`0` 為中立），極端值多為小樣本運氣波動，幾乎沒有球員能跨季穩定維持高 Clutch。
