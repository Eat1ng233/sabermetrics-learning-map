# Swing Path / Tilt（揮棒路徑傾角）

## 一句話定義
**Swing Path（Tilt）** 描述打者揮棒**在接觸之前**的形狀：揮棒路徑平面相對地面的垂直角度。

## 計算方式與核心邏輯
- 0° = 完全水平（與地面平行）的揮棒；90° = 真正的「高爾夫揮桿」。
- 角度越低越「平」（flat），越高越「陡」（steep／uppercut）。

## 基準值與判讀區間
- **MLB 平均約 32°**；球季範圍約 **20°（最平）至 50°（最陡）**。
- 2024 較平：Corbin Carroll 22°、Randy Arozarena 25°、Giancarlo Stanton 26°；較陡：Freddie Freeman 42°、Aaron Judge 40°、Nick Castellanos 39°。

## 演進脈絡與相關指標
- 與 [[metrics/Attack-Angle|Attack Angle]] 的差異：Swing Path 是整個揮棒平面；Attack Angle 是**接觸當下**棒頭移動的方向。與 [[metrics/Launch-Angle|Launch Angle]]（接觸後球的角度）也不同。屬 [[concepts/Bat-Tracking|Bat Tracking]]。

## 限制與常見誤區
- **陡或平沒有好壞**，只是揮棒類型的描述。
- 傾角會隨進壘點變化：打高球時較平、打低球時較陡，比較時需考慮投手配球位置。
