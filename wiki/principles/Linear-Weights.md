# 線性權重（Linear Weights）

## 一句話定義
**線性權重**是一種線性得分估計方法：透過計算每種場上事件（如保送、一壘打、全壘打）對「得分期望值（Run Expectancy）」的平均改變量，賦予各事件精確的得分權重，是 [[metrics/wOBA|wOBA]] 與 [[metrics/FIP|FIP]] 的數學基石。

---

## 推導步驟詳解（以 2015 年 wOBA 為例）

### 步驟一：建立 24 種壘包出局情境得分期望值矩陣（RE24）
Baseball 共有 3 種出局數（0, 1, 2）× 8 種壘包狀態 = **24 種狀態**。統計該狀態出現後直到該半局結束的平均得分（以下為 Tom Tango 計算之 2010–2015 基準）：

| 壘包狀態 | 0 出局 | 1 出局 | 2 出局 |
| :--- | :--- | :--- | :--- |
| `__ __ __`（無人） | 0.481 | 0.254 | 0.098 |
| `1B __ __` | 0.859 | **0.509** | 0.224 |
| `__ 2B __` | 1.100 | 0.664 | 0.319 |
| `1B 2B __` | 1.437 | **0.884** | 0.429 |
| `__ __ 3B` | 1.350 | 0.950 | 0.353 |
| `1B __ 3B` | 1.784 | 1.130 | 0.478 |
| `__ 2B 3B` | 1.964 | 1.376 | 0.580 |
| `1B 2B 3B` | 2.292 | 1.541 | 0.752 |

> 例：1 出局一壘有人（`0.509`）時獲得保送，變成 1 出局一二壘有人（`0.884`），該打席創造了 `+0.375` 分的得分期望增量。

### 步驟二：計算各事件相對於平均打席的得分貢獻
將整季所有該類事件（如所有非故意四壞保送）的 RE 變化加總除以事件總數，即得「相對於平均打席」的線性權重：
- `BB`: `+0.29`、`HBP`: `+0.31`、`1B`: `+0.44`、`2B`: `+0.74`、`3B`: `+1.01`、`HR`: `+1.39`、`Out`: **`-0.26`**

### 步驟三：將出局數歸零（對齊 OBP 直覺）
為了讓它像上壘率（OBP）一樣「出局 = 0」，將每個事件權重都加上 `+0.26`：

| 事件 | 相對出局的得分權重（2015） |
| :--- | :--- |
| **BB** | `0.55` |
| **HBP** | `0.57` |
| **1B** | `0.70` |
| **2B** | `1.00` |
| **3B** | `1.27` |
| **HR** | `1.65` |

### 步驟四：乘以 `wOBA Scale` 對齊聯盟 OBP 量尺
用上述權重算出 2015 年全聯盟初步平均值為 `0.250`，而當年聯盟扣除 IBB 後的 OBP 為 `.313`。因此：
$$
\text{wOBA Scale} = \frac{0.313}{0.250} = 1.251
$$
將上表權重全數乘以 `1.251`，即得該季正式 [[metrics/wOBA|wOBA]] 公式係數。（若推導 [[metrics/FIP|FIP]] 權重，則是將「場內球出局」而非所有出局歸零，再平移對齊聯盟 [[metrics/ERA|ERA]]。）

---

## 限制
線性權重是針對特定聯盟環境算出來的「一體適用平均估計值」，假設事件價值與壘包情境獨立；在極端高得分或極端低得分環境下，邊際價值會略有誤差。
