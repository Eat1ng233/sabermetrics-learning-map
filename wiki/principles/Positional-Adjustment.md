# 守備位置調整（Positional Adjustment）

## 一句話定義
**守備位置調整**是為了修正 [[metrics/UZR|UZR]]、[[metrics/DRS|DRS]] 等守備指標「僅與同守位聯盟平均比較」的限制，透過依守備難度與負荷量加減分數，將所有守位換算至同一基準線（即 [[metrics/Def|Def]]），以便計算 [[metrics/WAR|WAR]]。

---

## 為什麼需要位置調整？
一名游擊手（SS）比聯盟平均游擊手多守下 5 分得到 `+5`，一名左外野手（LF）比平均左外野手多守下 5 分也得到 `+5`。但游擊手處理的球數與難度遠高於左外野手——「平均游擊手」的真實守備價值遠高於「平均一壘手」或「指定打擊（DH）」。

---

## FanGraphs 標準調整表（每 1,458 守備局 / 162 場）

| 守備位置 | 整季調整分數（Runs） | 說明 |
| :--- | :--- | :--- |
| **C（捕手）** | **+12.5** | 守備負擔與技術門檻最高 |
| **SS（游擊手）** | **+7.5** | 內野守備難度與球量最高 |
| **2B（二壘手）** | **+2.5** | 中線守備位置 |
| **3B（三壘手）** | **+2.5** | 需反應強襲球與長傳 |
| **CF（中外野手）** | **+2.5** | 外野防區最大 |
| **LF（左外野手）** | **-7.5** | 角落外野守備負荷較低 |
| **RF（右外野手）** | **-7.5** | 角落外野（需較強臂力但範圍需求較小） |
| **1B（一壘手）** | **-12.5** | 守備難度最低之野手位置 |
| **DH（指定打擊）** | **-17.5** | 不參與守備 |

- **按比例計算**：若一壘手單季守備 `1,214` 局，其位置調整為 $-12.5 \times \frac{1214}{1458} \approx -10.4$ 分；多守位球員則依各守位局數分別計算後加總。

---

## 方法論限制與討論
- **經驗指引而非絕對定律**：這些數值源於早期研究「轉換守位球員前後表現差異」的推算，隨時代演變可能略有誤差（例如部分研究認為 DH `-17.5` 過於嚴苛，因為未守備可能影響打擊節奏；而捕手 `+12.5` 在納入偷好球 Framing 後可能偏高）。
- **非隨機選擇偏差**：球員不會隨機被分配守位（例如左撇子幾乎不守游擊，最頂尖的左撇子守備員只能去一壘或外野），這使得跨守位轉換的估計天生存在選擇偏差。
